# 柴犬探偵団 〜リビングに消ゆ〜

PC-8800風レトロテキストアドベンチャー。3頭の柴犬（雷蔵・はな・蔵之介）のうち2頭を相棒にして、
リビングから消えた何かの謎を「じゅんこ」と「たいち」2つの視点で追う。1人で両視点を操作しても、
2人でそれぞれの視点を担当してもプレイできる。

ビルドツール・依存パッケージなし。プレーンな HTML/CSS/JS のみで動作する PWA。

## 遊び方

### 1人プレイ

ロビーで「ひとりで遊ぶ」を選び、じゅんこ・たいち両方のバディ（柴犬）を選ぶとゲームが始まる。
【コマンド】欄の「▶視点を◯◯に切り替える」でいつでも視点を切り替えられる。数字キー（1, 2, 3…）
でコマンドを選択、Space / Enter で文字送りをスキップできる。

### 2人プレイ

Firebase が設定されている場合、ロビーに「部屋を作る」「部屋に入る」が現れる。

- ホスト（じゅんこ視点固定）: 「部屋を作る」→バディを選ぶ→発行された4桁のルームコードを相手に伝える。
- ゲスト（たいち視点固定）: 「部屋に入る」→ルームコードを入力→残っているバディを選ぶ。

各自は自分の視点だけを操作する。相手の推理や行動はリアルタイムで反映される。ルームは作成から
24時間で失効する。断線しても自分側の進行は止まらず、再接続すればまた同期される。

Firebase が未設定、または初期化に失敗した場合は自動的に1人プレイにフォールバックする（3択は出ない）。

## ローカルで動かす

```bash
python3 -m http.server 8767
```

ブラウザで `http://localhost:8767/` を開く。

## テスト

```bash
node --test test/*.test.js
```

## Firebase セットアップ（2人プレイに必要。任意）

1. [Firebase コンソール](https://console.firebase.google.com/) で新規プロジェクト `shiba-detective` を作成する。
2. Realtime Database を有効化する（リージョンは `asia-southeast1` または `asia-northeast1` を推奨）。
3. Authentication で「匿名」プロバイダを有効化する。
4. プロジェクトの設定値を `src/net/firebase-config.js` の `firebaseConfig` に書き込む（`apiKey` は秘密情報ではないため、コミットしてよい）。
5. Realtime Database のルールに `database.rules.json` の内容を反映する。
6. GitHub Pages 等で公開する場合は、Authentication > 承認済みドメインに公開先のドメイン（例: `<user>.github.io`）を追加する。忘れると本番で匿名認証が失敗し、常に1人プレイになる。

未設定のままでも1人プレイは問題なく動く。

## PWA

`manifest.json` と `sw.js` によりホーム画面への追加・オフラインでの1人プレイに対応する。
Service Worker はネットワーク優先で、オンラインなら常に最新のファイルを返し、オフラインの時だけ
キャッシュから返す（更新時に `sw.js` の `CACHE` を上げ忘れても古い JS が残らない）。外部CDN（Firebase SDK）は
横取りせず常にネットワークから取得する。`firebase-config.js` がプレースホルダーのままなら SDK を読み込まず、
最初から1人プレイで起動する。
